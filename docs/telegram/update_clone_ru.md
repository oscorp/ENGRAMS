**ENGRAMS: репозиторий теперь работает сразу после клонирования**

🤝 **Главное: этой серией я хочу собрать сообщество — людей, которым интересна эта работа и которые хотели бы присоединиться к проекту. Если это вы, напишите в группе обсуждения @sequence_memory.**

ℹ️ Публикации серии выходят в этом канале, а обсуждение и вопросы — в привязанной группе @sequence_memory. Так части идут в канале подряд и не теряются среди комментариев.

Я решил изменить ссылки и пути во всех частях. Раньше часть скриптов ждала данные по путям на моём компьютере, и воспроизвести шаги можно было, только переписав пути вручную. Теперь:

1. Все скрипты частей 1–4 запускаются из корня клона и читают и пишут только папки репозитория. Путей вне клона в коде нет.
2. В корне есть requirements.txt со всеми зависимостями.
3. Большие данные — 584 фрагмента корпуса (11,4 ГиБ) и потоки лемм — лежат на Hugging Face и скачиваются одной командой прямо на свои места: python scripts/fetch_data.py.
4. Фрагмент 2, на котором сняты все задачи, лежит прямо в репозитории вместе с его потоками.
5. Проверка за минуту без интернета: python scripts/smoke_test.py прогоняет конвейер частей 3–4 на маленьком примере.
6. Где что лежит и какие ссылки пока заглушки — отдельный список docs/DATA_PATHS.md: точное место каждой заглушки, на что её заменить и где взять данные.

Начать так:
git clone https://github.com/oscorp/ENGRAMS.git
cd ENGRAMS
pip install -r requirements.txt
python -m spacy download ru_core_news_lg
python scripts/smoke_test.py

Если что-то не запускается у вас — напишите в @sequence_memory, это тоже вклад в проект.
