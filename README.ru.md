ENGRAMS — модель языка, построенная на статистике корпуса вместо обратного распространения ошибки. Она считает, как часто слова встречаются на каждом расстоянии друг от друга, нормирует эти счётчики у кандидата (что превращает их в поточечную взаимную информацию) и предсказывает следующее слово геометрическим средним строк контекста, а также воспоминанием из памяти окон текста. Каждая строка и каждый столбец каждой матрицы — это слово, поэтому любой шаг предсказания можно прочитать и проследить до корпуса.

Чемпион на леммах русской Википедии (около 1,1 млрд объектов, словарь 100 005), точность первого места на 300 задачах:

| способ | leak | gen |
|---|---:|---:|
| воспоминание голосованием n-грамм | 94,00 | 33,67 |
| композиция по памяти окон, β = 32 | 92,00 | 26,00 |
| переключение по глубине совпадения | 98,67* | — |

\* замер на 150 отчётных задачах дампа нестрогого режима: +10/−0 против лучшего постоянного слияния (92,00), p = 0,002. *leak* — окно задачи есть в памяти; *gen* — окрестность задачи ±30 исключена. Память покрывает около 0,7 % корпуса, поэтому gen низкий; см. часть 19.

## Как запустить

Клон работает сразу: все скрипты запускаются из корня репозитория и пишут только в его папки.

```bash
git clone https://github.com/oscorp/ENGRAMS.git && cd ENGRAMS
pip install -r requirements.txt
python -m spacy download ru_core_news_lg     # модель spaCy для частей 3–4
python scripts/smoke_test.py                 # проверка конвейера частей 3–4 на маленьком примере
```

То же в Jupyter: `%pip install -r requirements.txt`, затем `!python …` для каждой команды.

| часть | команда |
|---|---|
| 1–4, рисунки | `python docs/figures/make_part01_figures.py` … `make_part04_figures.py` |
| 2, рабочие 300 задач | `python scripts/part02/select_tasks.py` |
| 3, корпус | `python scripts/fetch_data.py --what corpus`, проверка `python scripts/part03/check_manifest.py` |
| 3, подготовка строки | `python scripts/part03/preprocess_v3.py --demo` |
| 4, потоки | `python scripts/fetch_data.py --what streams` или сборка `python scripts/part04/build_streams_v3.py` |

Где лежат данные, что скачивается с Hugging Face и какие ссылки пока заглушки: [docs/DATA_PATHS.md](docs/DATA_PATHS.md).

## Устройство репозитория

```
docs/articles/{ru,en}/   статьи, по одной на часть и язык

requirements.txt         зависимости всех частей
```
