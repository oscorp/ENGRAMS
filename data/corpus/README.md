# Корпус / Corpus

**RU.** `corpus_manifest_v3.json` — манифест 584 исходных текстовых фрагментов русской Википедии, по которым собран токенизатор v3 (часть 3). Для каждого фрагмента: имя файла, размер в байтах, md5, число статей (по строкам `### Заголовок ###`) и первый заголовок. Сами фрагменты (11,4 ГиБ) лежат на Hugging Face и скачиваются в `data/corpus/chunks_584/` командой `python scripts/fetch_data.py --what corpus`; в git — только фрагмент 2 (на нём набор задач части 2). Сверка с манифестом: `python scripts/part03/check_manifest.py`. Подготовка текста — `scripts/part03/preprocess_v3.py`. Лицензия: CC BY-SA 4.0, данные производны от Википедии.

**EN.** `corpus_manifest_v3.json` is the manifest of the 584 raw text fragments of the Russian Wikipedia from which tokenizer v3 was built (part 3). For each fragment: file name, size in bytes, md5, number of articles (by lines `### Title ###`) and the first title. The fragments themselves (11.4 GiB) are on Hugging Face and are downloaded into `data/corpus/chunks_584/` with `python scripts/fetch_data.py --what corpus`; only fragment 2 (the part 2 task set) is in git. Check against the manifest: `python scripts/part03/check_manifest.py`. Text preparation: `scripts/part03/preprocess_v3.py`. License: CC BY-SA 4.0, derived from Wikipedia.
